# H1–H4: selective hypotheses and falsification criteria

## H1: exact query complexity and stronger ideal certification

The counting proof in LINEAR_QUERY_COMPLEXITY.md gives the lower bounds on
linear cubic tensors. The upper bound can now use deterministic local labels
(H2 below); no random classical runtime is necessary in the ideal model.
This is a candidate strengthening, not independent peer review.

For a nonzero residual alternating trilinear form T, its radical
R={a:T(a,b,c)=0 for every b,c} has codimension at least three: choose
u,v,w with T(u,v,w)=1. Their images modulo R are independent (evaluate a
linear combination against the other two basis vectors). A uniform a is
in R with probability at most 1/8. Otherwise the alternating matrix
T(a,.,.) has rank at least two, so a uniform b lies in its kernel with
probability at most 1/4. Hence Pr[D(a,b)=0] <= 11/32, tight for a single
triple. Independent uniform ideal holdout with r masks has false accept
<= (11/32)^r for a fixed incorrect cubic tensor, versus the previous
single-bit bound (5/8)^r. For delta=.01, five checks suffice rather than
ten. The same argument gives Pr[T(a,b,c)=1]>=21/64 for a third random
c; this could improve the classical comparator stopping constant.
Neither bound applies to noncubic or arbitrarily corrupted oracles.
Keep previous ten-check defaults and matched comparisons unchanged.
Exhaustive finite rank counts for all nonzero cubic graphs on 4 and 5
vertices test the sharp bound. No adversarial seed security claim.

## H2: deterministic polynomial-time local code selection

Each new label must avoid at most Delta subspaces, each of dimension
<=Delta-1 in F2^r, r=Delta+ceil(log2 Delta)+1. Their summed size is less
than 2^r. For a specified high-bit prefix, project each subspace onto
the prefix coordinates. If the prefix is not in the image, its
intersection is empty. Otherwise every fiber has cardinality
2^(rank(original)-rank(projected)), computed by binary elimination.
Choose each next bit to minimize the sum of these counts. The two
counts sum to the previous count; therefore after r steps the sum is
strictly less than one. It is an integer, hence zero. This constructs
a permissible label deterministically in polynomial time (even a
naive implementation is polynomial in n and Delta). The label width
and number of query masks do not increase. No hidden tensor is used.
When r>=n the previous unit-mask fallback remains. Optional holdout
still uses randomness; exact promised recovery itself does not require
it. Claim: ideal Theta(d log n) with deterministic polynomial decoding
in the specified linear class, subject to independent proof and novelty
review. Conditional counting and Gaussian elimination are standard
techniques. Compare against existing graph learning, not just our
previous random implementation. Falsify by rank deficiency, incorrect
recovery or superpolynomial label construction.

## H3: phase cycling, conditional on inverse access

Let V=U_f diag(exp(-i theta(x))) be diagonal and repeatable, with a real
unwrapped phase error theta. If both V and its exact adjoint V† can
be called, choose a sector (p,q) in {0,1}^2, applying the four shifted
copies with signs (-1)^(p*i+q*j) on x XOR i*a XOR j*b. Negative signs
mean inverse calls, not noiseless pulse reversal. All sectors implement
the same ideal Boolean-sign derivative. The real residual phase r(x)
has Walsh coefficient 4*theta_hat(s) precisely when s·a=p,s·b=q
and zero otherwise. Ignore its constant term (global phase). Thus
Var(r)=16 sum of theta_hat(s)^2 in that sector for s != 0.

The probability of wrong BV word equals 1-|E_x exp(-i r(x))|^2.
Using independent x,y and 1-cos z<=z^2/2, it is <=Var(r).
For a uniformly sampled sector, average word error <=4 Var(theta),
since the four sectors partition the nonconstant Fourier coefficients.
Forward-only has bound <=16 Var(theta). This is an average per-probe
bound over randomized controls, not a guarantee of improvement on
each instance or a hardware BSC model. Expected inverse calls =1.5
per four-call probe, worst case two. If inverse access is unavailable
or noisy independently, the proof does not justify implementation.
Also theta depends on phase unwrapping; this bound is useful only when
a physically justified small real error representation is available.
Benchmarks retain cases where mixing is worse. No general robustness
or optimality claim.

## H4: a matched-access classical-processing baseline

A phase oracle alone does not reveal f(x) on a basis state. For x!=0,
prepare (|0^n>+|x>)/sqrt(2) using H on a set bit and CNOT fanout,
call the same U once, reverse preparation and measure that bit.
The result is exactly f(x) XOR f(0) for an ideal Boolean sign oracle;
for x=0 no call. This is a quantum-assisted single-bit evaluation with
classical decoding, not a purely classical physical operation. Global
constant cancels from cubic recovery. No controlled-U or inverse needed.
In an all-to-all control model this uses 2(wt(x)-1) CNOTs and two H
gates, excluding oracle cost, routing, measurement and reset. Under
phase perturbations the probability of bit 1 is
(1-Re[V_x conjugate(V_0)])/2. The classical sparse value algorithm can
therefore use the very same ideal phase access, one oracle call per
nonzero distinct word, with these physical control costs. Test relative
phase formula and compare counted calls and control resources. Query
separation is not physical advantage: per-shot noise, inverse cost,
preparation, routing, readout and classical computation must be charged.
No device offering opaque quantized diagonal access has been identified.
Generic Hamiltonian learning also allows broader models, see
https://arxiv.org/abs/2410.21635 (time reversal model) and
https://link.springer.com/article/10.1007/s00220-025-05517-w.
The 2026 time-reversal property testing literature is a relevant
additional comparison: https://arxiv.org/abs/2610.04996. Novelty of
phase cycling itself is not established. No QPU submitted.

## Experiment protocol

benchmarks.hypotheses: two fixtures n=4/6, four phase scales, eight
independently drawn offset vectors each, sixteen random masks per
vector, 1024 paired probability observations. Exact Walsh probabilities;
no physical gate noise. Five disjoint-Pasch sizes compare deterministic
and randomized known-support decoders and the single-bit evaluation
cost of classical_sparse. Fixed seed 301, explicit raw fields. Not
matched noisy end-to-end accuracy or resource timing. Stop before
hardware if the access/cost assumptions cannot be realized.
